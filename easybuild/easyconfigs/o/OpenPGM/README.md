# OpenPGM

-   [OpenPGM on Google code](https://code.google.com/p/openpgm/)

-   There are some newer releases on a [GitHub site that claims to be an automatic export of the 
    Google Code site](https://github.com/steve-o/openpgm).

    In fact, Fedora offers the newer 5.3.128 release, but Red Hat enterprise versions still offer
    5.2.122. So we decided to stick to that version, as is also done in the EasyBuilders repsository.
