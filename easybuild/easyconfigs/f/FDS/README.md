# FDS technical information

FDS or Fire Dynamics Simulator is a large-eddy simulation (LES) code for
low-speed flows, with an emphasis on smoke and heat transport from fires.

-   [FDS-SMV web page](https://pages.nist.gov/fds-smv/)

-   [FDS on GitHub](https://github.com/firemodels/fds)

    -   [GitHub releases](https://github.com/firemodels/fds/releases)
